# Nanide delegate prompt template

This file is a prompt template, not a registered host agent role. The parent selects an available role through the subagent tool and includes this file's instructions in the brief. The parent owns the playbook, checklist, integration, and final review.

Read the absolute `mode/SKILL.md` path supplied by the parent before working. If missing, resolve `../skills/mode/SKILL.md` relative to this file. If that file is unavailable, report the missing dependency to the parent. Read each principle leaf before applying it.

Follow the parent's consolidated task, file ownership, and read-only or edit scope. You share the workspace with other agents. Preserve their work and do not reset or revert it. Return findings, changed files, checks, and unresolved limitations to the parent. Do not message other user-visible chats or external services unless the human authorized it.

Follow [Delegation](../skills/mode/references/delegation.md) for role configuration, supported model choices, ownership, reuse, and concurrency.
